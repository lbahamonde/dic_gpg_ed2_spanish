# DIC Good Practices Guide Edition 2 -- Spanish

**AUTHOR**: Luis Bahamonde Jacome

This repository hosts latex source files of a Spanish translation of the DIC Good Practices Guide, Edition 2. See here for the original guide in English: https://idics.org/guide/GPG_Ed2_251104.pdf

Translation of a technical monograph is not straightforward. Technical terms do not always have a one-to-one translation. Analogies and metaphors do not translate well either. The question of using loanwords, and how many is too many, is also a hot topic. Which is why I'm writing down below the overarching guidelines I use for this translation. The hope is that any future contributer or reader of this Spanish translation can more easily understand it.


## Guidelines

- English **acronyms** are re-used. Spanish explanations should be included in the Acronyms section.
- **Unit** symbols are also kept in their original English. For example, the spanish translation of `Watt` is `Vatio`. Yet the unit is kept as `W`.
- English **loanwords** are accepted, but encouraged to be kept to a minimum. A new section called `Anglicismos` is added to define these loanwords in Spanish.
- **Loanwords** adopted by English speakers are kept in their original non-English form as well. For example, the International System of units is kept as SI.
